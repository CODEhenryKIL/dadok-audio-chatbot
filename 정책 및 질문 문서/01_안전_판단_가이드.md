# 안전 판단 가이드

## 목적
질문의 검색 경로나 답변 자료를 결정하지 않고, **이 질문에 어떤 수준으로 답해도 되는지**만 판단한다.

## 처리 순서
`룰 기반 → 명확하면 확정 → 애매하면 GPT-5 nano`

- 모델: `GPT-5 nano`
- Reasoning: `none`
- 룰 미매칭 또는 여러 안전 룰 충돌 시 LLM으로 넘긴다.
- 검색 대상 결정은 이 단계에서 하지 않는다.

## 안전 결과

- `ALLOW`: 일반 답변 허용
- `GUIDE`: 위험한 판단·지시 부분만 제한하고 허용 가능한 정보는 제공
- `BLOCK`: 위험 요청은 수행하지 않고 안전한 안내로 전환
- `EMERGENCY`: 일반 답변보다 즉각적인 안전 안내를 우선

## 안전 유형

1. 질병 진단
2. 질병 확률·위험도
3. 병원·응급실 방문 판단
4. 약물 용량·복용 간격
5. 개인 맞춤 치료 지시
6. 정상·비정상·괜찮음 판정
7. 사진·음성·검사 판독
8. 기록 기반 원인 추론
9. 회복·악화·예후 예측
10. 처방 변경·중단
11. 개인 맞춤 수유·영양
12. 발달장애·정신·신경 판정
13. 응급·사고·중독·질식
14. 자해·타해·아동학대 위험
15. 의료진 역할 대체

## 룰 기반 우선 대상

다음 유형은 명확한 표현 조합을 우선 검사한다.

- 3. 병원 방문 판단
- 4. 약물 용량·복용
- 10. 처방 변경·중단
- 13. 응급 상황
- 14. 자해·타해·학대
- 15. 의료진 역할 대체

### 룰 작성 원칙

- 단일 키워드만으로 차단하지 않는다.
- `대상 + 상태/행동 + 요청 의도`를 함께 본다.
- 일반 정보, 예방 질문, 이미 한 행동의 기록 요약은 과도하게 제한하지 않는다.
- 현재 대화 문맥을 함께 확인한다.
- 여러 룰이 충돌하거나 판단이 불명확하면 LLM으로 넘긴다.
- 룰을 통과했다고 안전한 질문으로 확정하지 않는다.

## 우선순위

1. `13·14` 응급 / 실제 위해 / 자해·타해·학대
2. `4·10` 약물 / 처방 변경
3. `1·2·3·5·7·12` 개인 의료 판단
4. `6·8·9·11` 정상성 / 원인 / 예후 / 수유·영양
5. `15` 의료진 역할 대체

## 최소 출력 스키마

```json
{
  "safety_action": "ALLOW | GUIDE | BLOCK | EMERGENCY",
  "safety_types": []
}
```

필요 이상의 필드는 추가하지 않는다.

## 핵심 원칙

- 안전 판단은 **“어떻게 답해도 되는가”**만 결정한다.
- **어떤 DB/RAG를 조회할지는 검색 판단 모듈이 전담한다.**
- 위험한 부분만 제한하고, 허용 가능한 정보는 계속 제공한다.
